Cómo implementar cada trigger de n8n en grapScreen

grapScreen no necesita 111 integraciones nativas: seis triggers genéricos cubren todo el catálogo.

Los seis triggers de grapScreen

Programado (cron) → intervalos y expresiones cron

Cubre Schedule Trigger, Cron e Interval.

Webhook → servidor HTTP propio

El servicio hace POST a tu URL. Cubre todo trigger de app que soporte webhooks, más Webhook, MCP Server y los de agentes.

Polling (API) → consulta periódica

Consulta un endpoint cada N segundos y dispara cuando la respuesta cambia. Es el comodín para las apps que no ofrecen webhooks.

Cambio de archivo → vigila una ruta

Cubre Local File Trigger.

Atajo de teclado → atajo global del sistema

Sin equivalente en n8n. Es diferencial de grapScreen.

Al iniciar → al arrancar la app

Cubre n8n Trigger.

Además, Manual (botón Ejecutar), Formulario (pedir datos a una persona) y Manejar error (puerto de error) cubren los disparadores de control.

Reparto de los 111 triggers

El payload del trigger llega a los nodos siguientes como items: se lee con {{ $json.campo }}. Si la respuesta es un array JSON, se despliega en un item por elemento. También queda disponible en {{ $vars.polling.body }}.
